================================================================
  EDGEBUG SOUND — что добавлено в лобо
================================================================

ЧТО ДЕЛАЕТ
----------
Когда edge bug срабатывает (чит нашёл и выполняет эджбаг),
проигрывается твой .wav звук.

КАК УКАЗЫВАТЬ ПУТЬ
------------------
В меню: Movement -> галка "edge bug" -> "edgebug sound".
Под галкой появится поле ввода пути и кнопка "play test sound".

Путь указывается в формате папки, например:
    C:\lobotomy\sounds
и из этой папки будет играть файл edgebug.wav
(т.е. итоговый файл: C:\lobotomy\sounds\edgebug.wav)

Можно указать и полный путь прямо до файла:
    C:\lobotomy\sounds\mysound.wav
(если путь заканчивается на .wav — он используется как есть)

Кавычки и лишние пробелы при вставке пути обрезаются автоматически.
Путь сохраняется в конфиг (.lobotomy) и загружается оттуда.

================================================================
  SPECTATOR LIST — новый дизайн списка спектаторов
================================================================

Список спектаторов (кто смотрит на тебя) переделан под новый
дизайн: тёмная панель с двойной рамкой, заголовок "spectators"
по центру, под ним ЦВЕТНАЯ полоска и чёрный бокс со списком ников.

ЦВЕТ ПОЛОСКИ меняется в меню:
Misc -> general -> галка "spectator list" -> "line color".
По умолчанию — синяя (0, 148, 255), как на скриншоте-примере.

Панель появляется в правом верхнем углу экрана (под watermark
и media player, если они включены) и видна, даже если спектаторов
нет — так же, как на примере.

Работает, когда в галке "spectator list" выбран режим
"all spectators" (стоит по умолчанию). Старый текстовый режим
"local spectators" остался как был.

================================================================
  TEXTURE BUG — перенесён из сурсов def (botox)
================================================================

Автоматический texturebug: сам находит вертикальную стенку рядом,
ловит "залипание" в шве текстур (vz зажимается движком в
-(sv_gravity * dt / 2)) и едет по стене, сохраняя скорость.
Звук при детекте СПЕЦИАЛЬНО НЕ перенесён (просили без него).

ГДЕ ВКЛЮЧИТЬ
------------
Меню -> Movement -> галка "texture bug". Внутри попапа:
    texture bug key — клавиша активации (hold)
    reach           — радиус поиска стены (0-48 u, по умолч. 8)
    types allowed   — ducking / standing (какие стойки ловить)
    wallstrafe      — добор скорости вдоль стены во время заезда

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Включи галку, назначь клавишу.
2. Прыгни вдоль стены (стенки/уступа) и зажми клавишу.
3. Чит сам подберёт нажатие и прилипнет к шву — дальше просто
   держи клавишу и управляй камерой.
4. Работает и как auto-align на земле: побежал к стене с
   зажатой клавишей — сам подстроит разбег и прыжок.

================================================================
  КАК СОБРАТЬ .DLL (для тех, кто никогда не собирал)
================================================================

ШАГ 1. Установи Visual Studio 2022 Community (бесплатно)
--------------------------------------------------------
1. Зайди на сайт: https://visualstudio.microsoft.com/ru/downloads/
2. Скачай "Community 2022" и запусти установщик.
3. В окне установщика поставь галку на рабочей нагрузке:
      "Разработка классических приложений на C++"
   (англ. "Desktop development with C++")
4. Нажми "Установить". Это займёт 10-30 минут.
5. Больше ничего устанавливать НЕ нужно: DirectX SDK и все
   библиотеки уже вшиты в этот проект (папка
   dependencies/dxsdk-d3dx и x86-windows-static-md).

ШАГ 2. Распакуй архив
---------------------
Распакуй ВЕСЬ архив в любую папку, например C:\lobosource
(главное — путь без кириллицы, лучше просто C:\...).

ШАГ 3. Собери
-------------
1. Открой папку с проектом.
2. Дважды кликни по файлу  build.bat
3. Жди 3-15 минут (в первый раз дольше всего).
4. В конце увидишь [OK] BUILD SUCCESSFUL!

Visual Studio 2026 тоже подходит: build.bat сам находит VS 2026
или VS 2022 и подбирает компилятор. Если в VS 2026 установлен
тулсет v143 (компонент "MSVC v143 - VS 2022 C++ x64/x86 build
tools") — соберёт на нём; если нет — автоматически переключит
проект на v145, компилятор VS 2026. Ничего вручную менять не надо.

Если появилось [ERROR] MSBuild not found — значит Visual Studio
не установлена или установлена без C++ нагрузки (см. ШАГ 1).

ГДЕ ЛЕЖИТ ГОТОВАЯ DLL
---------------------
После сборки:  release\fart.dll   (32-битная, как и нужно для CS:GO)

Это и есть чит — его и инжектишь в игру своим лоадером.

Если хочешь собрать Debug-версию (для отладки): открой csgo-sdk.sln
в Visual Studio, выбери сверху "Debug | x86" и нажми СБОРКА ->
Собрать решение. DLL появится в папке debug\zipudhe2.dll

ОШИБКИ ПРИ СБОРКЕ
-----------------
0. Универсальное правило: сначала запусти check_source.bat
   (лежит рядом с build.bat). Он проверит, что все файлы
   исходника на месте, и сам починит битый include в
   frame_stage_notify.cpp (ошибки вида "Cannot open include
   file: '../../hg/debug.h'" появляются из-за битого архива
   при скачивании — распаковался мусор).
- "Cannot open include file: 'd3dx9.h'" — не должно появиться,
  я вшил d3dx9 в проект. Если вдруг появилось — распаковал архив
  не полностью, проверь что есть папка dependencies\dxsdk-d3dx.
- MSB8040 / "v143" не установлен — либо доустанови в Visual Studio
  Installer компонент "MSVC v143 - VS 2022 C++ x64/x86 build tools",
  либо просто запускай build.bat: он сам переключит проект на
  компилятор v145 из VS 2026.
- Ошибки LNK2038 ("_ITERATOR_DEBUG_LEVEL" / "RuntimeLibrary" /
  "MDd_DynamicDebug") или LNK2019 ("__imp___CrtDbgReport") — это
  мусор от старой сборки. Запусти delete_cache.bat (он удалит
  папки intermediates/debug/release), потом снова build.bat.
- Любая другая ошибка — скопируй красные строки из окна сборки.

================================================================
  WATERMARK — 7 стилей и свой текст
================================================================

ГДЕ ВКЛЮЧИТЬ
------------
Меню -> галка "watermark" (рядом с "media player").
Ватермарка рисуется в правом верхнем углу.

ЧТО ВНУТРИ ГАЛКИ (раскрой чекбокс watermark)
--------------------------------------------
  watermark style  — выбор стиля (7 штук):
     1. classic    — тёмная плашка с обводкой, белый текст (без эффектов)
     2. minimal    — только текст с лёгкой тенью, без плашки (без эффектов)
     3. gradient   — анимированный градиентный баннер, текст с обводкой
     4. rainbow    — тёмная плашка, текст переливается цветами радуги
     5. glow pulse — тёмная плашка, текст «дышит» свечением
     6. neon       — неоновая переливающаяся рамка + свечение текста
     7. accent bar — тёмная плашка с цветной полосой слева и подчёркиванием

  watermark text   — свой текст ватермарки (по умолчанию labuba).
                     Если оставить пустым — покажется пробел,
                     чтобы плашка не схлопнулась в ноль.

ПРИМЕЧАНИЕ
----------
Текст и стиль сохраняются в конфиг (.lobotomy) и подхватываются
при следующем запуске. Все стили той же высоты (29px), поэтому
media player и остальные элементы, как и раньше, автоматически
встают ниже ватермарки.

================================================================
  СКИНЧЕНДЖЕР ( из def ) — вкладка Inventory
================================================================

Старый инвентарь убран. Вместо него — полноценный скинченжер:
ножи, скины на оружие, стикеры, агенты и перчатки.

ГДЕ НАСТРОИТЬ
-------------
Меню -> Inventory. Две под-вкладки:

  WEAPONS  - скины оружия + нож
  PLAYER   - агенты + перчатки

WEAPONS
-------
  enable weapon skins  - вкл/выкл скины на оружие
  weapon               - выбор пушки ( 34 ствола )
  paint kit            - список скинов с поиском
  wear / pattern       - износ ( float до 1.0 ) и паттерн ( сид 0-1023 )
  stattrak + kills     - статтрек и счётчик
  name tag             - своя надпись на оружии
  custom color         - свои 4 цвета палитры ( работают палитровые
                         стили скинов; "original" стиль их игнорирует )
  sticker slot 1-5     - стикеры: кит с поиском, wear/scale/rotation
  update               - применить вручную
  reset skins          - сбросить все скины оружия

  KNIFE ( правая колонка ):
  enable knife + knife model ( 23 ножа ), paint kit, wear,
  pattern, stattrak, name tag, custom color
  enable knife anims   - анимации от другого ножа ( если кости
                         не подходят - будет предупреждение )
  fix view             - фикс камеры у shadow daggers

PLAYER
------
  agents     - enable agents, t/ct агент ( ~130 штук, поиск ),
               "custom models" - свои .mdl из csgo\models\player
  gloves     - enable gloves, 9 моделей перчаток, paint kit,
               wear, pattern

ОБЕ КОМАНДЫ
-----------
  "same skins on both teams" - один набор на T и CT.
  Иначе: кнопки terrorist / counter terrorist переключают набор,
  "copy from terrorist/ct" копирует настройки между командами.
